# Scientific profiles and local validation

The array API now defaults to the geophysics profile selected solely on the expanded synthetic validation partition. The packaged geophysics_calibration.json records the chosen method and threshold, physical scales in cell units, bank digest and frozen protocol. Calling profiles() exposes that calibration through the public API; callers must not maintain independent copies. Explicit method and threshold arguments remain available for sensitivity analysis.

The previous array defaults are available as legacy-array: THDR at 0.2. The legacy TDR array method remains selectable separately. Neither claims equivalence to the full v1.2 file pipeline. That pipeline remains available through run_extraction_job with geophysics_profile set to legacy-v120, the CLI option --geophysics-profile legacy-v120, and the own QGIS Processing/panel profile selector. Its numerical line_core implementation is preserved. File geophysics uses the new calibration by default. Existing calls with explicit historical filters select legacy-v120 unless the caller explicitly selects the calibrated profile; numeric curvature controls apply only to legacy-v120. Reports distinguish requested historical controls from the effective calibration. Existing source-bound adaptive recipes retain legacy-v120 unless the caller explicitly selects the calibrated profile, preserving their recorded execution contract.

The new default changes outputs deliberately; it is not v1.2 parity. Other input modes retain their existing numerical paths. Heights and scales of the calibrated profile are multiples of native cell size; continuation height is not inferred source depth. The implementation is global in memory and does not certify regional scalability.

Wavelet processing reflects a full filter support and subtracts the datum before cropping and normalization, avoiding artificial zero-extension edges. Ridge suppression requires negative Hessian curvature. See [diagnosis](research/DIAGNOSTICO_WAVELETS_20261115.md) and the [frozen protocol](research/PROTOCOLO_BANCOS_MEJORA_20261115.md). The correction has a datum-invariance/localization regression, while scientific effectiveness is measured separately.

The campaign uses 3000 independent 128 by 128 Harmonica scenes, three TEED seeds and validation-only parameter selection. Test superiority requires a positive paired F1 confidence interval and noninferiority of position error within 0.5 cells. Real evaluation measures concordance with published fault maps at 250/500/1000 m, detection density and axial orientation. Mapped faults are not magnetic ground truth. Three Australian regions share the GA compilation; they do not represent three independent data providers. The results and all limits are retained in the permanent task report, without distributing model weights.

MIRAGE remains a local development branch; no publication, tag or release is implied by this documentation. TEED stays experimental unless the preregistered criteria are met separately in each benchmark.
