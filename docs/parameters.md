# Parameters

- <code>RADI</code>: smoothing radius used on tonal rasters before edge detection.
- <code>GTHR</code>: edge sensitivity threshold used by the Canny-based path.
- <code>LTHR</code>: minimum extracted skeleton length in pixels.
- <code>FTHR</code>: polyline simplification tolerance in output map units.
- <code>ATHR</code>: maximum angular difference allowed when linking segments.
- <code>DTHR</code>: maximum endpoint distance in pixels allowed when linking segments.
